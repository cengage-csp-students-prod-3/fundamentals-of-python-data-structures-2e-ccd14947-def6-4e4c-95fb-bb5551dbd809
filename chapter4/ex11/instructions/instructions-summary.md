This exercise asks you to define some functions for manipulating linked structures. You should use the `Node` and `TwoWayNode` classes, as defined in this chapter.

In the *testnode.py* file complete the following:
1. Complete the implementation of the `makeTwoWay` function that expects a singly linked structure as its argument.
	- The function builds and returns a doubly linked structure that contains the items in the singly linked structure.
	
> Note: The function should not alter the argument’s structure.

To test your program run the `main()` method in the *testnode.py* file.

Your program's output should look like the following:
```
5 4 3 2 1: 5 4 3 2 1 
5 4 3 2 1: 5 4 3 2 1
```
