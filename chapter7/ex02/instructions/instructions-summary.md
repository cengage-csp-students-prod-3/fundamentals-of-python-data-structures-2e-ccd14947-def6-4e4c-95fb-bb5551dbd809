Write a program that uses a `stack` to test input strings to determine whether they are __palindromes__. A palindrome is a sequence of characters that reads the same as the sequence in reverse; for example, _noon_.

>Be sure to reuse your solution from *Programming Exercise 7.1* as your starter file for the *arraystack.py* and *linkedstack.py* files.

In the *palindrome.py* file, complete the following:
1. Read the characters from an input string using an ArrayStack
	- Returns True if string is a palindrome or False otherwise.

To test your program run the `main` method in the *palindrome.py* file.

Your program's output should look like the following:
```
Enter a string or Return to quit: noon
It's a palindrome
Enter a string or Return to quit: hello
It's not a palindrome
Enter a string or Return to quit: 
```
> The test above tested the strings **noon** and **hello**. You're not limited to the strings you can test.
