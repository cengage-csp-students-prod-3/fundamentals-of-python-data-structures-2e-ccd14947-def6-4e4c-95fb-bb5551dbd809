Python’s `pow` function returns the result of raising a number to a given power.

1.  Define a function `expo()` that performs this task. The first argument of this function is the __base number__,
  and the second argument is the __exponent__ (nonnegative numbers only). You can use either a loop or a recursive function in your implementation, but do not use Python’s `**` operator or `pow` function. 
2.  State its computational complexity using big-O notation in the docstring. 

To test your program run the `main()` method in the *expo.py* file.

Your program's output should look like the following:
```
0 1
1 2
2 4
3 8
4 16
```
